## 4. Langkah Build dan Run Program via Visual Studio Code (VS Code)

1. Buka Folder Proyek:
   Buka folder proyek Project_FormPendaftaran melalui VS Code (File > Open Folder).
2. Kompilasi (Compile / Build):
   - Buka terminal di VS Code (Terminal > New Terminal).
   - Pastikan direktori aktif berada di dalam folder `src`.
   - Jalankan perintah kompilasi berikut:
     javac Pertemuan2/Tugas2/FormPendaftaran.java
3. Menjalankan Program (Run):
   - Jalankan perintah berikut di terminal:
     java Pertemuan2.Tugas2.FormPendaftaran
   - Aplikasi GUI pendaftaran kegiatan akan terbuka secara otomatis melalui Event Dispatch Thread (EDT).
